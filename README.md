Keloğlan Elma Hesaplayıcı
Bu proje, Keloğlan masal kahramanlarının (Keloğlan, Balkız ve Keloğlan'ın Anası) sahip olduğu elmaların toplam sayısını hesaplayan basit bir Python betiğidir.

Ne İşe Yarar?
Kod sırasıyla şu işlemleri gerçekleştirir:

Karakterlerin elma sayılarını tanımlar (Keloğlan: 10, Balkız: 5, Ana: 20).

Bu sayıları aralarında virgül olacak şekilde yan yana ekrana yazdırır.

Elmaların toplam sayısını matematiksel olarak toplar ve değişkene atar.

Çıkan sonucu hem tek başına hem de anlaşılır bir metinle birlikte ("Toplam Elma Sayısı : ...") ekrana basar.
